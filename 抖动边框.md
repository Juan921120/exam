要用代码完美复现 `图层-2.png` 和 `watermarked_img_1145261910174115796.png` 中这种**圆润、带有手绘水彩质感和不规则边缘**的按钮，单靠传统的 CSS 属性（如 `border-radius`）是无法做到那种自然的手绘线条感的。

在前端开发中，最地道且拓展性最强的方案是**结合 CSS 和 SVG (Scalable Vector Graphics)**。

以下是实现该风格的核心技术方案与代码：

---

## 核心实现思路

1. **不规则圆角（Hand-drawn Borders）**：使用 SVG 的 `path` 绘制一个带有微小随机抖动的圆角矩形，或者使用 CSS 的 `border-radius` 配合多组数值制造不对称感。
2. **水彩/噪点质感（Texture & Gradient）**：利用 SVG 的 `feTurbulence`（滤镜）来生成类似纸张或水彩的粗糙颗粒感，并配合渐变色。
3. **高光与内阴影（Glow & Highlight）**：在左上角和右下角叠加半透明的白色椭圆或线条，模拟果冻质感的高光。

---

## 技术要点解析

### 1. 为什么用 SVG `rect` 代替 CSS `border-radius`？

如果只用 CSS 的 `border-radius: 35px;`，渲染出来的边缘是绝对几何完美的。为了实现图片中那种“人类用铅笔画出来的”微小抖动感，代码中引入了 SVG 滤镜 `feTurbulence`（湍流算法）和 `feDisplacementMap`（位移映射）。它会动态地将矩形平滑的边缘**随机揉碎、扭曲**，从而完美模拟出纸张和手绘线条的质感。

### 2. 颜色与阴影细节

* **边框色（Stroke）**：图片中的边框不是纯黑色，而是比背景色稍深一点的同系色（粉色配深粉红边，绿色配深绿边）。
* **字体颜色**：避免使用 `#000000`。原图采用的是一种温暖的**深巧克力色/深棕色 (`#4a3c31`)**，这才是维持整体 UI 温暖治愈风的关键。
* **高光层 (`.highlight-tl`)**：原图中左上角有一道明显的白色“果冻光泽”。在代码中，我们用一个带透明度的绝对定位元素，通过 `border-radius: 50%` 压缩成椭圆，再配合 `transform: rotate()` 轻微旋转来精确复现。
